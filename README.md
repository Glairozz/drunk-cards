# 🍻 Drunk Cards

A fun party drinking game with 104+ challenges! Built with HTML, CSS, and JavaScript.

## Features

- 🎴 **104+ Unique Cards** - Never get bored with diverse drinking challenges
- 🎨 **Premium Design** - Sleek dark theme with smooth animations
- ✨ **Smooth Animations** - 3D card flips, particles, and transitions
- 📱 **Mobile Responsive** - Works great on any device
- 🔄 **Undo Function** - Made a mistake? Go back!
- 🎮 **Easy Navigation** - Simple 3-screen flow

## How to Play

1. Click "Start Party" to begin
2. Read the rules
3. Click "Draw Card" to reveal a challenge
4. Complete the challenge or drink!

## Rules

- Draw cards and complete the challenge
- When someone skips a card, they drink 2x
- Have fun and drink responsibly!

## Demo

Open `index.html` in your browser to play!

## Tech Stack

- HTML5
- CSS3 (Animations, Gradients, Glassmorphism)
- Vanilla JavaScript
